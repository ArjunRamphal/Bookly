## 2023-10-29 - Explicit Semantic onClickLabels in Compose
**Learning:** When using standard Compose modifiers like `clickable` on custom components or non-button containers (e.g., `ListItem`, `Box`), screen readers often default to generic announcements (like "double tap to activate"). This lacks context, making the interface less accessible for users relying on assistive technologies. Standard properties like `contentDescription` on internal icons are sometimes overridden or ignored in these larger interactable areas.
**Action:** Always provide an explicit `onClickLabel` (and `onLongClickLabel` if applicable) within `clickable` or `combinedClickable` modifiers for custom UI components to ensure the screen reader clearly describes the resulting action (e.g., `onClickLabel = "Select folder"`).
